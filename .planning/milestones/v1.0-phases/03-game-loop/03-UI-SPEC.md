# Phase 3 — UI Design Contract: Game Loop

> Visual and interaction contract for Phase 3. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none — hand-rolled CSS Modules |
| Preset | not applicable |
| Component library | none |
| Icon library | none — text labels only |
| Font | Inter (sans, UI chrome) + Georgia (serif, scenario text) — system fonts, no external load |

Source: RESEARCH.md / CLAUDE.md decision — "The design spec is specific enough that a component library will fight you constantly." CSS Modules established in Phases 1–2.

## Spacing Scale

Declared values (multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline label padding, choice button border-radius adjustment |
| sm | 8px | Gap between meter label and bar, player card padding, gap in vote tally rows |
| md | 16px | Default element spacing, section padding within right panel |
| lg | 24px | Section breaks within host right panel, player phone padding (horizontal) |
| xl | 32px | Major layout gaps, top/bottom padding on scenario card |
| 2xl | 48px | Host panel vertical padding |
| 3xl | 64px | Page-level outer padding on host dashboard |

Exceptions:
- Choice buttons: minimum touch target 44px height (phone accessibility, slightly outside 8pt grid — intentional)
- Content note dismiss button: 44px minimum height (same touch target rule)
- Timer bar height: 8px (matches MeterBar track/fill height for visual consistency)

## Typography

| Role | Family | Size | Weight | Line Height | Usage |
|------|--------|------|--------|-------------|-------|
| Body | var(--sans) | 16px | 400 | 1.5 | General UI text, labels, meta copy |
| Label | var(--sans) | 14px | 600 | 1.4 | Framework label badge, meter names, tally % labels, content note header |
| Scenario | var(--serif) | 18px | 400 | 1.65 | Scenario body text — full-width on phone, large serif for reading |
| Display | var(--sans) | 28px | 600 | 1.1 | Timer countdown number, consequence text headline |

Font declarations:
- `var(--serif)`: Georgia, 'Times New Roman', serif (already in index.css)
- `var(--sans)`: 'Inter', system-ui, -apple-system, sans-serif (already in index.css)

Notes:
- Scenario title on host right panel and section headings use 16px at weight 600 (Body role, weighted) — no separate Heading size.
- All weighted elements (section headings, percentage numbers, meter values, display numbers) use weight 600. Weight 700 is not used.

Source: Established in src/index.css — `font: 16px/1.5 var(--sans)` on `:root`. Scenario serif confirmed in CLAUDE.md: "Scenario text: Georgia, serif."

## Color

| Role | Token | Hex | Usage |
|------|-------|-----|-------|
| Dominant (60%) | var(--bg) | #0a0a14 | Page backgrounds, host dashboard background, city placeholder panel |
| Secondary (30%) | var(--bg-surface) | #12121e | Cards, right panel, player phone scenario card, vote tally rows, player cards |
| Accent (10%) | var(--accent) | #f59e0b | See reserved list below |
| Accent hover | var(--accent-hover) | #d97706 | Button hover state only |
| Accent background | var(--accent-bg) | rgba(245,158,11,0.1) | Locked choice button fill, framework label badge background |
| Text primary | var(--text-h) | #f5f5f5 | Headings, scenario text, consequence text |
| Text body | var(--text) | #e5e5e5 | Body copy, choice button text |
| Text muted | var(--text-muted) | #6b7280 | Meta labels, player count, timer label, city placeholder text |
| Danger | var(--danger) | #ef4444 | Meter bar fill when value < 20; timer bar/number when < 10 seconds |
| Border subtle | — | #2e303a | Card borders, panel dividers (from existing Host.module.css) |

Accent (`var(--accent)`) reserved for:
1. Close Round button (primary host action per round)
2. Next Round button (primary host action between rounds)
3. Locked choice button border/indicator (player confirmation state)
4. Framework label badge text
5. "X of Y submitted" count number (the X)
6. Active meter bar fill (normal range, value >= 20)
7. Timer countdown number (normal range, >= 10 seconds)

Second semantic color (`var(--danger)`) reserved for:
1. Meter bar fill when world state value drops below 20
2. Timer countdown number and bar when under 10 seconds

Source: Tokens defined in src/index.css. Decision D-20 from CONTEXT.md: "Meter bar color: amber (var(--accent)) for normal range, shifts to red (var(--danger)) if below 20." Decision D-04: "Color shifts to red/amber when under 10 seconds."

## Component Inventory

New components required for Phase 3:

### ScenarioCard (src/components/ScenarioCard.jsx + ScenarioCard.module.css)
- Renders scenario title, weight tag, body text, and 3 choice buttons
- Used in: Play.jsx (full screen, phone-optimized)
- States: default (all buttons enabled) | locked (one button selected, others dimmed)
- Choice button: 44px min-height, full-width, bg-surface with var(--text) border 1px solid #2e303a
- Locked choice: border-color var(--accent), background var(--accent-bg), framework label revealed below
- Dimmed choices (after lock): opacity 0.4, cursor default
- Scenario text: var(--serif), 18px, line-height 1.65, color var(--text-h)
- Choice button text: var(--sans), 16px, weight 400
- Scenario title: var(--sans), 16px, weight 600 (Body role, weighted)

### ContentNote (src/components/ContentNote.jsx + ContentNote.module.css)
- Used on Rounds 3 and 4 before ScenarioCard displays
- Full-screen overlay on player phone
- Elements: warning label (14px, var(--text-muted), uppercase, tracked), note text (16px body), "Continue to round" button (primary), "Pass this round" link (text, no background)
- "Pass this round" is a plain text link styled with var(--text-muted), underline on hover — never accented, to avoid drawing attention

### FrameworkLabel (src/components/FrameworkLabel.jsx + FrameworkLabel.module.css)
- Appears below consequence text after round closes (NOT during choice)
- Badge-style: background var(--accent-bg), border 1px solid var(--accent), border-radius 4px
- Text: 14px, weight 600, var(--accent) — framework name
- Subtitle: 14px, weight 400, var(--text-muted) — 1-sentence explanation
- Entrance: `opacity: 0` to `opacity: 1`, `transform: translateY(4px)` to `translateY(0)`, duration 300ms ease, delay 400ms after consequence text fades in

### VoteTally (src/components/VoteTally.jsx + VoteTally.module.css)
- Host right panel: live anonymous vote percentage per choice
- 3 rows, one per choice option
- Each row: choice label (truncated to 40 chars), percentage bar (CSS, bg var(--accent), height 8px, border-radius 4px), raw count + percentage text
- Bar width: `width: ${pct}%`, `transition: width 0.4s ease`
- Labels: 14px var(--sans), var(--text-muted)
- Percentage number: 14px, weight 600, var(--text-h)
- "X of Y submitted" line: 14px var(--text-muted), X rendered in var(--accent) weight 600

### MeterBar (src/components/MeterBar.jsx + MeterBar.module.css)
- CSS-only bar, no SVG animation (deferred to v2)
- Props: `label` (string), `value` (0–100)
- Track: full width, height 8px, background #2e303a (border subtle), border-radius 4px
- Fill: `width: ${value}%`, `transition: width 0.8s ease`, background var(--accent) when value >= 20, var(--danger) when value < 20
- Label row: meter name (14px, weight 600, var(--text-muted)) left, value number (14px, weight 600, var(--text-h)) right
- Stacked 4 in a column with 16px gap between each
- Used in: WorldStatePanel (host) and Play.jsx consequence section (phone)

### WorldStatePanel (src/components/WorldStatePanel.jsx + WorldStatePanel.module.css)
- Host right panel section — contains scenario title, VoteTally, 4 MeterBar instances, timer display, submitted counter, Close Round button
- Width: 40% of host layout (right panel)
- Background: var(--bg-surface), border-left 1px solid #2e303a
- Padding: 24px
- Internal layout: flex column, gap 24px between major sections

### TimerDisplay (src/components/TimerDisplay.jsx + TimerDisplay.module.css)
- Host and player: shows remaining seconds
- Large number: 28px, weight 600, var(--accent) when >= 10s, var(--danger) when < 10s
- Thin progress bar below number: 8px height, same color logic, `transition: width linear` synced to 1s interval
- Bar shrinks left-to-right: `width: ${(remaining / total) * 100}%`
- Label: "Time remaining" 14px var(--text-muted) above the number

### ConsequenceReveal (src/components/ConsequenceReveal.jsx + ConsequenceReveal.module.css)
- Replaces ScenarioCard on player phone when round closes
- Entrance: ~1 second pause (CSS animation-delay 1s), then fade in
- Consequence text: 18px var(--serif), line-height 1.65, var(--text-h), centered
- Below consequence: FrameworkLabel component
- Below FrameworkLabel: 4 MeterBars
- Background: var(--bg), full screen, padding 32px 24px

### CityPlaceholder (src/components/CityPlaceholder.jsx + CityPlaceholder.module.css)
- Host left panel (~60% width): dark panel with city silhouette SVG or reserved label
- Background: var(--bg) (slightly darker than surface)
- Centered content: simple SVG skyline silhouette in #1a1a2a (just visible against bg), label "City View" in 14px var(--text-muted) uppercase tracked, below silhouette
- Must not look broken — reserved, intentional. Source: D-06 CONTEXT.md.

### HostRoundLayout (layout wrapper in Host.jsx, no separate file needed)
- Two-column flex: left (city placeholder, flex 3 ~60%), right (WorldStatePanel, flex 2 ~40%)
- Gap: 0 (panel border-left provides visual separation)
- Height: 100vh

## Interaction States

### Choice Button Flow (PLAY-04, PLAY-05, PLAY-06)

```
idle → hover → tap → [optimistic lock] → locked
                           |
                           v
                    other buttons dim (opacity 0.4)
                    locked button: accent border + accent-bg fill
                           |
                     [round closes]
                           v
                    consequence text fades in (1s delay)
                    framework label enters (delay 400ms after consequence)
                    meters animate to new values (transition: width 0.8s ease)
```

No second submission possible once locked. CSS `pointer-events: none` on all buttons after lock. No server round-trip needed to lock UI — optimistic update on tap, Supabase insert fires in background.

### Content Note Flow (PLAY-09)

```
round_active (heavy round) → ContentNote overlay
         |
    [Continue to round] → ScenarioCard displays
    [Pass this round] → neutral waiting screen ("You sat this one out")
                              → still receives consequence + meters on round close
```

### Round Close Flow (HOST-05, HOST-06)

```
host right panel during round:
  [Close Round] button (always visible, amber) — single click, no confirmation dialog
  OR timer hits 0 (auto-close)
         |
         v
  Supabase: sessions.status → 'round_complete'
  All players detect via subscription → trigger consequence reveal
  Host sees: vote tally frozen, meters animate to new values
         |
    [Next Round] button appears
         v
  sessions.status → 'active', current_round incremented
  All players: return to waiting/scenario state
```

## Animation Contract

All animations use CSS only (no Framer Motion — per RESEARCH.md decision).

| Element | Property | Duration | Easing | Notes |
|---------|----------|----------|--------|-------|
| Choice button lock | border-color, background | 150ms | ease | Immediate on tap |
| Choice button dim | opacity | 150ms | ease | Siblings fade simultaneously with lock |
| Vote tally bar | width | 400ms | ease | Fires on each new submission via subscription |
| Meter bar fill | width | 800ms | ease | Fires once when round closes and world state updates |
| Consequence reveal | opacity, transform (translateY 8px → 0) | 400ms | ease | 1000ms animation-delay |
| Framework label | opacity, transform (translateY 4px → 0) | 300ms | ease | 400ms delay after consequence starts |
| Timer bar | width | 1000ms | linear | Steps once per second; color changes at 10s mark |
| Timer color shift | color, background | 200ms | ease | Smooth shift from accent to danger at < 10s |
| Meter color shift (danger) | background-color | 600ms | ease | Fires when value crosses 20 threshold |
| Round transition | opacity on page root | 300ms | ease | Between round_complete and next active round |

## Player Phone Layout Spec

All views: max-width 480px, centered, padding 24px horizontal, padding 32px top.
Full-screen vertical scroll permitted only if scenario text is long.

### Scenario View (during round)
```
[Avatar emoji] [Player name]
[Round N]
─────────────────────────────
[CONTENT NOTE if heavy round]
  "A note before this round"
  [one sentence]
  [Continue to round]  [Pass this round]
─────────────────────────────
[Scenario title — 16px sans 600]

[Scenario body — 18px serif, line-height 1.65]

[Choice A button — full width, 44px min]
[Choice B button — full width, 44px min]
[Choice C button — full width, 44px min]

[Timer display — centered]
```

### Submitted State (after tap, before round closes)
```
[Locked choice — accented, other choices dimmed]
[Checkmark or "Submitted" label — var(--text-muted)]
[Waiting for others... — var(--text-muted)]
[X of Y submitted — X in var(--accent)]
[Timer display — read-only]
```

[1-sentence explanation — 14px muted]

[World State — section header muted uppercase]
[Trust meter bar]
[Courage meter bar]
[Solidarity meter bar]
[Awareness meter bar]
