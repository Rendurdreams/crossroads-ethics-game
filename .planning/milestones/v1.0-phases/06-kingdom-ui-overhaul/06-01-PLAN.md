- Render a single `<svg>` element with `viewBox="0 0 800 500"`, `preserveAspectRatio="xMidYMid meet"`, `width="100%"`, `height="auto"`, `aria-label="Kingdom Map"`, `role="img"`
- Background rect: `<rect width="800" height="500" fill="#0a0a14" />`
- Terrain layer (SVG polygons/paths — exact coordinates are your discretion per UI-SPEC guidance):
  - Mountains: upper-right quadrant, 3-4 polygon peaks, fill `#1a1a2e` / `#16162a`
  - River: diagonal S-curve from upper-center to lower-right, stroke width 8-12px, fill `rgba(59,130,246,0.18)`
  - Coastal shelf: lower-right, fill `rgba(59,130,246,0.08)`
  - Forest: left side, 5-7 triangle trees, fill `#141428`
  - Village mound: center-left raised polygon, fill `#16162a`
  - Ground plane: low rectangle at bottom, fill `#14142a`
- Four landmark groups, each a `<g>` with `className` set from CSS module tier class:
  - Bridge of Accord (trust): river crossing area, arch bridge with two piers + horizontal span, ~80px wide
  - Citadel Beacon (courage): mountain peak, tower 12px wide x 35px tall, pointed cap, single upward ray line (stroke only)
  - Village Quarter (solidarity): center-left mound, 3 small house rects (12x10px) with chimney
  - Fog of the Vale (awareness): lower-left, semi-transparent horizontal ellipse — for this landmark, the CSS class controls opacity differently: flourishing=0.15, neutral=0.35, declining=0.6 (fog INCREASES when awareness DECLINES)
- Landmark `<text>` labels: 8px below each landmark centroid, `textAnchor="middle"`, `fontFamily="var(--serif)"`, `fontSize="13"`, `fill="rgba(245,158,11,0.6)"`, `letterSpacing="0.1em"`. Labels: "Bridge of Accord", "Citadel Beacon", "Village Quarter", "Fog of the Vale"
- className on each landmark `<g>`: use `styles[trustTier]` etc (from CSS module)
