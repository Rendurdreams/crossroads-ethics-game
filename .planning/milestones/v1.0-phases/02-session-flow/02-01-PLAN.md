  <action>
    Build Landing.jsx with two distinct sections — HOST and PLAYER — on a single page (per HOST-01, PLAY-01, PLAY-02).

    **Layout:** Centered column, max-width 480px, dark background. Game title "The Crossroads" at top in serif font, subtitle "A Multiplayer Ethics Game" below in muted text. Two sections below separated by a thin amber divider line.

    **Host section (top):**
    - Heading: "Host a Game"
    - Single button: "Create Game" — amber background, dark text, bold
    - On click: call createSession()
    - createSession():
      1. Set loading state to true, disable button
      2. const code = generateRoomCode() (import from '../lib/roomCode.js')
      3. const { data, error } = await supabase.from('sessions').insert({ room_code: code }).select().single()
      4. If error (unique constraint collision on room_code): retry once with a new code. If second attempt fails, show "Failed to create session. Try again."
      5. On success: navigate(`/host/${data.id}`) using useNavigate() from react-router-dom
      6. Set loading state to false on error

    **Player section (bottom):**
    - Heading: "Join a Game"
    - Room code input: 4 digit numeric, placeholder "Room Code", maxLength 4, inputMode="numeric", pattern="[0-9]*" (brings up numeric keyboard on phones)
    - Name input: text, placeholder "Your Name", maxLength 20
    - Join button: disabled unless code is exactly 4 chars AND name is at least 1 char (trimmed)
    - Error message area: initially hidden, shows red text on errors
    - On Join click: call joinSession()
    - joinSession():
      1. Set loading state, disable inputs
      2. Query session: const { data: session } = await supabase.from('sessions').select('id, status').eq('room_code', code.trim()).maybeSingle()
         - Use .maybeSingle() NOT .single() (returns null if no match, not an error)
      3. If !session: show "Room not found. Check the code and try again."
      4. If session.status !== 'lobby': show "This game has already started."
      5. Pick random avatar from AVATARS array:
         const AVATARS = ['fox-face', 'bear', 'panda', 'lion', 'tiger', 'unicorn', 'frog', 'octopus', 'butterfly', 'crab', 'dolphin', 'owl', 'wolf', 'hedgehog', 'penguin', 'cat']
         Actually use real emoji: const AVATARS = ['\u{1F98A}', '\u{1F43B}', '\u{1F43C}', '\u{1F981}', '\u{1F42F}', '\u{1F984}', '\u{1F438}', '\u{1F419}', '\u{1F98B}', '\u{1F980}', '\u{1F42C}', '\u{1F989}', '\u{1F43A}', '\u{1F994}', '\u{1F427}', '\u{1F431}']
         const avatar = AVATARS[Math.floor(Math.random() * AVATARS.length)]
      6. Insert player: const { data: player, error } = await supabase.from('players').insert({ session_id: session.id, name: name.trim(), avatar }).select().single()
      7. If error: show "Failed to join. Try again."
      8. localStorage.setItem('player_id', player.id)
         localStorage.setItem('session_id', session.id)  (per PLAY-02, PLAY-03 preparation)
      9. navigate(`/play/${session.id}`)
      10. Clear loading state on any error
