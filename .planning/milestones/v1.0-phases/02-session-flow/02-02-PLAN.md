  <action>
    Build Play.jsx — the player's phone view for the lobby (per PLAY-03).

    **Component structure:**
    - Import useParams, useNavigate from "react-router-dom"
    - Import useState, useEffect from "react"
    - Import { supabase } from '../lib/supabase.js'
    - Extract sessionId from useParams()

    **State:**
    - const [player, setPlayer] = useState(null) — restored player data
    - const [session, setSession] = useState(null) — session row
    - const [playerCount, setPlayerCount] = useState(0) — live count
    - const [loading, setLoading] = useState(true) — initial restore check
    - const [gameStarted, setGameStarted] = useState(false) — host pressed start

    **useEffect on mount — session restore (PLAY-03):**
    1. Read localStorage: const storedPlayerId = localStorage.getItem('player_id'), const storedSessionId = localStorage.getItem('session_id')
    2. If storedPlayerId AND storedSessionId === sessionId (URL param):
       - Fetch player: supabase.from('players').select('*').eq('id', storedPlayerId).single()
       - If data exists: setPlayer(data), proceed to fetch session
       - If no data (stale localStorage): localStorage.removeItem('player_id'), localStorage.removeItem('session_id'), navigate('/')
    3. If no stored identity OR storedSessionId !== sessionId:
       - navigate('/') — redirect to landing to join properly
    4. After player confirmed, fetch session: supabase.from('sessions').select('*').eq('id', sessionId).single()
       - setSession(data)
       - If session.status !== 'lobby': setGameStarted(true)
    5. Fetch player count: supabase.from('players').select('id', { count: 'exact' }).eq('session_id', sessionId)
       - setPlayerCount(count)
    6. setLoading(false)

    **useEffect — subscribe to player count changes:**
    - Subscribe to players INSERT for this session (same pattern as Host but just incrementing count):
      supabase.channel(`play-players:${sessionId}`)
        .on('postgres_changes', { event: 'INSERT', schema: 'public', table: 'players', filter: `session_id=eq.${sessionId}` },
          () => { setPlayerCount(prev => prev + 1) })
        .subscribe()
    - Cleanup: removeChannel

    **useEffect — subscribe to session status changes:**
    - Subscribe to sessions UPDATE for this session:
      supabase.channel(`play-session:${sessionId}`)
        .on('postgres_changes', { event: 'UPDATE', schema: 'public', table: 'sessions', filter: `id=eq.${sessionId}` },
          (payload) => {
            setSession(payload.new)
            if (payload.new.status === 'active') setGameStarted(true)
          })
        .subscribe()
    - Cleanup: removeChannel
    - This wires the "game started" signal so Phase 3 can build from it.

    **Render layout:**
    - If loading: centered "Loading..." text
    - If gameStarted: show "Game is starting..." centered amber text (Phase 3 replaces this with round view)
    - Lobby waiting state:
      - Player's avatar (large, centered): font-size 3rem
      - Player's name: below avatar, color var(--text-h), font-size 1.2rem
      - "Waiting for host to start..." in muted text, centered
      - Player count: "{playerCount} player(s) in room" in muted text
      - Room code reminder: small muted text showing the session room code
