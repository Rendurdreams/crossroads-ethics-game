    **Script structure:**

    1. **Header comment block:**
       ```
       // Load Test: 25 Concurrent Supabase Real-Time Subscriptions
       //
       // Verifies that 25 simultaneous channels all receive INSERT events
       // on the choices table within 2 seconds of being written.
       //
       // Usage:
       //   SUPABASE_URL=https://xxx.supabase.co SUPABASE_ANON_KEY=xxx node scripts/load-test.js
       //
       // Pass criteria: all 25 channels receive all events within 2000ms.
       // A single dropped event is a failure.
       ```

    2. **Constants:**
       ```javascript
       const CHANNEL_COUNT = 25
       const EVENT_COUNT = 10
       const TIMEOUT_MS = 2000
       ```

    3. **Environment validation:**
       Read `process.env.SUPABASE_URL` and `process.env.SUPABASE_ANON_KEY`. If either is missing, print usage instructions and `process.exit(1)`.

    4. **Create Supabase client:**
       ```javascript
       import { createClient } from '@supabase/supabase-js'
       const supabase = createClient(SUPABASE_URL, SUPABASE_ANON_KEY)
       ```

    5. **Create a test session:**
       Insert a new session row with a unique room code (use `Math.random().toString(36).slice(2, 6)`) and status `'lobby'`. Store the session ID.

    6. **Create a test player:**
       Insert a player row linked to the test session. Store the player ID. This player will be used as the `player_id` for test choice inserts.

    7. **Open 25 channels:**
       Each channel subscribes to `postgres_changes` on the `choices` table filtered by `session_id=eq.${sessionId}`. Wait for all 25 channels to reach `SUBSCRIBED` status before proceeding:
       ```javascript
       const received = Array.from({ length: CHANNEL_COUNT }, () => [])
       const channels = []

       console.log(`[LOAD TEST] Opening ${CHANNEL_COUNT} subscriptions to session ${sessionId}...`)

       await Promise.all(
         Array.from({ length: CHANNEL_COUNT }, (_, i) =>
           new Promise((resolve) => {
             const ch = supabase
               .channel(`load-test-${i}`)
               .on('postgres_changes', {
                 event: 'INSERT',
                 schema: 'public',
                 table: 'choices',
                 filter: `session_id=eq.${sessionId}`
               }, (payload) => {
                 received[i].push(payload.new.id)
               })
               .subscribe((status) => {
                 if (status === 'SUBSCRIBED') resolve()
               })
             channels.push(ch)
           })
         )
       )

       console.log(`[OK] All ${CHANNEL_COUNT} channels active.`)
       ```

    8. **Insert test events:**
       ```javascript
       console.log(`[TEST] Writing ${EVENT_COUNT} choice inserts...`)

       for (let r = 0; r < EVENT_COUNT; r++) {
         await supabase.from('choices').insert({
           session_id: sessionId,
           player_id: playerId,
           round_number: r + 1,
           scenario_id: `load-test-scenario-${r}`,
           choice_index: r % 3,
           frameworks: ['consequentialism']
         })
       }
       ```

       Note: The choices table has a UNIQUE(player_id, round_number) constraint. Since we use a single test player, each insert uses a different round_number (1 through EVENT_COUNT). EVENT_COUNT=10 exceeds the max 6 rounds but the constraint is player_id + round_number, and the test creates its own player, so this works as long as we don't duplicate round numbers.

       Wait: Actually the game has max 6 rounds. Let's use 6 events instead of 10 to stay within realistic bounds and avoid constraint issues. Change `EVENT_COUNT = 6`.

       **Correction:** Set `const EVENT_COUNT = 6` (not 10).

    9. **Wait for delivery:**
       ```javascript
       await new Promise((resolve) => setTimeout(resolve, TIMEOUT_MS))
       ```

    10. **Evaluate results:**
        ```javascript
        let passCount = 0
        for (let i = 0; i < CHANNEL_COUNT; i++) {
          if (received[i].length >= EVENT_COUNT) {
            passCount++
          }
        }

        if (passCount === CHANNEL_COUNT) {
          console.log(`[RESULT] ${passCount}/${CHANNEL_COUNT} channels received all ${EVENT_COUNT} events within ${TIMEOUT_MS}ms — PASS`)
        } else {
          console.log(`[RESULT] ${passCount}/${CHANNEL_COUNT} channels received all events — FAIL (${CHANNEL_COUNT - passCount} channels dropped events)`)
          for (let i = 0; i < CHANNEL_COUNT; i++) {
            if (received[i].length < EVENT_COUNT) {
              console.log(`  Channel ${i}: received ${received[i].length}/${EVENT_COUNT}`)
            }
          }
        }
        ```

    11. **Cleanup:**
        Remove all channels, delete the test session (CASCADE will delete the test player and choices):
        ```javascript
        for (const ch of channels) {
          await supabase.removeChannel(ch)
        }
        await supabase.from('sessions').delete().eq('id', sessionId)
        console.log('[CLEANUP] Test session removed.')
        process.exit(passCount === CHANNEL_COUNT ? 0 : 1)
        ```
