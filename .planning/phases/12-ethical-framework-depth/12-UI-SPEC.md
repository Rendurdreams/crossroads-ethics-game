## Spacing Scale

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding, rank badge internals |
| sm | 8px | Gap between stance options, gap between choice rows in log |
| md | 16px | Default element spacing, section padding inside cards |

- Touch targets (choice buttons, stance tiles, awareness prompt dismiss area): minimum 44px height — matches existing `min-height: 44px` on `.submitBtn` and `.choiceBtn`

## New Element Specifications

### Awareness Prompt Banner (Play.jsx)

**Trigger:** Player has `top_value === 'honesty'` AND `stance.lie_to_protect === 'no'` AND current scenario has any care-tagged choice

**Placement:** Above `<ScenarioCard>` in normal document flow. Below round header.

**Layout:**
```
┌─────────────────────────────────────┐  ← glass card, 12px border-radius
│  ⚠  This choice prioritizes         │  ← 16px Inter, var(--text)
│     loyalty over truth. You         │
│     declared truth matters most.    │
│                              [✕]    │  ← dismiss tap target, full banner is tappable
└─────────────────────────────────────┘
```

**CSS contract:**
- Background: `rgba(245, 158, 11, 0.06)` (matches `.frameworkSection` in ConsequenceReveal)
- Border-left: `3px solid var(--accent)` (matches `.frameworkSection` pattern)
- Border-radius: `0 10px 10px 0`
- Padding: `16px`
- Margin-bottom: `16px`
- Font: Inter, 16px, weight 400, line-height 1.5, color `var(--text)`
- Entrance animation: `fadeUp 300ms ease forwards` — same keyframe as other elements, no delay
- Dismiss: `display: none` on tap — no fade-out animation (instant removal keeps interaction snappy)
- The entire banner area is the tap target (no separate close button needed)

**Copy (locked from D-17):** "This choice prioritizes loyalty over truth. You declared truth matters most."

### Moral Arc Section (FrameworkProfile.jsx)

**Trigger:** Dominant framework changed between early rounds (1-2) and late rounds (5+)

**Primary visual anchor role:** This is the highest-weight new section on the end screen. Its amber-bordered `.conflictSection` glass card treatment distinguishes it from subsequent sections (Character, Rights Awareness) which use lighter border treatments. Executor should ensure this section renders with full amber glow — not the subtle variant.

**CSS:** Use existing `.conflictSection` pattern — glass card with amber border, 24px padding, `margin-top: 16px`

**Eyebrow label:** "YOUR MORAL ARC" — 14px Inter, uppercase, letter-spacing 0.1em, `var(--text-muted)`

**Heading:** Playfair Display, 21px, weight 400, line-height 1.75, `var(--text-h)` — states the shift in plain language. Example: "In the early rounds you reasoned from Care Ethics. By the final rounds, you shifted to Deontology."

**Philosophical explanation:** Inter, 16px, weight 400, line-height 1.6, `var(--text)` — names the philosophical meaning (D-11).

**Consistency label (shown when no shift):** Inter, 16px, weight 400, `var(--text)` — "Your reasoning was remarkably consistent — you held [X] through escalating stakes." Uses `.leastUsedSection` style (border-top divider, no glass card).

### Character Section (FrameworkProfile.jsx)

**Trigger:** ≥2 virtue choices made

**CSS:** `.conflictSection` glass card pattern, `margin-top: 16px`

**Eyebrow:** "CHARACTER" — same eyebrow style

**Content lines:**
- Longest virtue streak: Inter, 16px, `var(--text)` — "You held to character for X consecutive rounds."
- Heavy-round count: Inter, 16px, `var(--text)` — "Virtue was your choice in X of Y high-stakes rounds."

### Moral Friction Count (FrameworkProfile.jsx)

**Trigger:** ≥1 moral conflict registered

**CSS:** `.leastUsedSection` style — `padding: 24px 0`, `border-top: 1px solid var(--glass-border-subtle)`

**Content:**

- Secondary line: Inter, 16px, italic, `var(--text-muted)` — "That tension is the point."

### Rights Awareness Line (FrameworkProfile.jsx)

**Trigger:** ≥2 rights-dimension scenarios played

**CSS:** `.leastUsedSection` style — border-top divider, 24px padding

**Content:** Inter, 16px, `var(--text)` — "In X of Y rights-critical scenarios, you chose to protect individual rights over group benefit."

### Cultural Context Footer (FrameworkProfile.jsx)

**Trigger:** Always shown (pack data always available)

**CSS:** `padding: 24px 0`, `border-top: 1px solid var(--glass-border-subtle)`, `opacity: 0.8`

- Lens line: Inter, 16px, `var(--text)` — "Your choices were measured in the context of [ethical lens]."
- Context note: Inter, 14px, `var(--text-muted)` — "A different context might have drawn different reasoning."

### Pack Ethical Lens Subtitle (HostSetup.jsx)

**Placement:** Below `.packDescription` text within each `.packCard`

**CSS:** `margin-top: 8px; font-family: var(--sans); font-size: 14px; font-style: italic; color: var(--text-muted);`

**No new class needed if inline style used; add `.packLens` to HostSetup.module.css if preferred.**

## Interaction States

### Baseline Stance Questions (3 new questions)

All states match existing Q1/Q2 pattern:
- **Default:** Glass-bg tile, subtle border (`var(--glass-border-subtle)`)
- **Hover:** `border-color: var(--glass-border)` + `box-shadow: 0 0 12px rgba(245,158,11,0.2)` (200ms ease)
- **Selected:** `border-color: var(--accent)` + amber glow ring + `background: rgba(245,158,11,0.12)` — re-selectable (D-03 from CONTEXT)
- **Focus-visible:** `outline: 2px solid var(--accent); outline-offset: 2px`

### Awareness Prompt Banner

- **Visible:** Fades in with `fadeUp 300ms ease forwards` on scenario load
- **Dismissed:** Instant `display: none` — no animation
- **Tap target:** Full banner area (no isolated close button required)
- **Keyboard:** If focused, Enter/Space dismisses

### End Screen Sections (new conditional sections)

- All new sections participate in the existing Framer Motion stagger (`containerVariants` / `sectionVariants` in FrameworkProfile.jsx)
- Each section fades up at its natural stagger position
- Sections that don't meet data threshold render null — no placeholder shown (D-28)

## Accessibility

- All new interactive elements (awareness prompt dismiss, new stance tiles) meet 44px minimum touch target height
- New stance tiles re-use existing `.valueCard` keyboard pattern: `focus-visible` outline at 2px solid `var(--accent)`, offset 2px
- Awareness prompt: `role="alert"` to announce to screen readers on appearance; dismissible via keyboard (Enter/Space)
- All new text meets contrast requirements: `var(--text)` (#e5e5e5) on `var(--glass-bg)` (dark surface) — exceeds 4.5:1 WCAG AA
- `var(--text-muted)` (#6b7280) on dark surface — used only for labels/eyebrows at 700 weight or uppercase, not for primary reading content
- End screen new sections: no heading hierarchy changes required — use `<p>` for narrative content, `<h2>/<h3>` not needed given the section/card visual structure
