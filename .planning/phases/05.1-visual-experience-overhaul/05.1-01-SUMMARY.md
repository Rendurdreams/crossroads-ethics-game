# Phase 05.1 Plan 01: Foundation Layer Summary

## One-Liner

Atmospheric CSS foundation with Playfair Display/Inter fonts, 7 glass-morphism tokens, ambient gradient drift layer, and AnimatePresence page transitions wired into App.jsx.

## What Was Built

### Task 1: Install framer-motion, Google Fonts, CSS foundation
- Installed `framer-motion@^11.13.5` (React 19 compatible)
- Added Google Fonts preconnect headers + Playfair Display + Inter at weights 400/700
- Updated `--serif` token from Georgia fallback to `'Playfair Display', Georgia, serif`
- Added 7 new atmospheric CSS custom properties to `:root`: `--glow-amber`, `--glow-amber-strong`, `--glow-cool`, `--glass-bg`, `--glass-border`, `--glass-border-subtle`, `--blur-glass`
- Added `@keyframes ambientDrift` with 14s 4-stop position cycle
- Added `.ambientLayer` class: `position: fixed; inset: 0; z-index: 0; pointer-events: none` with 14s infinite ambient drift animation

### Task 2: Restructure App.jsx with ambient layer and AnimatePresence
- Split single `App` component into `App` (BrowserRouter wrapper) + `AppRoutes` (inner component where `useLocation` is safely called)
- Added `<div aria-hidden="true" className="ambientLayer" />` as decorative background element on all routes
- Wrapped `Routes` with `<AnimatePresence mode="wait">` and passed `location` + `key={location.pathname}` for route change detection
- Build completes cleanly: 458 modules, no errors

## Decisions Made

| Decision | Rationale |
|----------|-----------|
| framer-motion ^11.13.5 | React 19 peer dep requires this minimum; API surface unchanged from 11.x |
| App + AppRoutes split | `useLocation()` must be inside `BrowserRouter` — calling it in App itself throws at runtime |
| Global CSS class for ambientLayer | The ambient layer is a single global element; CSS Modules would add unnecessary scope; this is the one intended exception |
| AnimatePresence mode="wait" | Ensures exit animation completes before enter fires — creates the cinematic fade-through effect per D-11 |
| Two font weights only (400, 700) | Per UI-SPEC typography section — no weight 600 to keep font request lean |
