# Phase 05.1: Visual Experience Overhaul - Context

**Gathered:** 2026-03-25
**Status:** Ready for planning

<domain>
## Phase Boundary

Transform the existing functional-but-flat UI into a premium, atmospheric, emotionally resonant game experience. This is a visual/styling overhaul of all existing pages and components. No new game features, no new mechanics, no new data flows. The game already works — this phase makes it feel like it matters.

</domain>

<decisions>
## Implementation Decisions

### Atmospheric Mood & Tone
- **D-01:** Emotional register is **cinematic dark** — deep blacks, warm amber glows, subtle gradient washes, vignette edges. Feels like a film title sequence: heavy, contemplative, matching the moral gravity of the content.
- **D-02:** Ambient background effect: **slow-moving radial gradients** that drift behind content. Pure CSS, no canvas. The screen should never feel static — subtle color washes keep it alive.
- **D-03:** World state meters **affect the visual atmosphere** via color tint shifts. As meters drop, ambient gradients shift cooler/darker. High meters warm the palette. The whole screen subtly reflects the collective state of the city.

### Typography & Text Presentation
- **D-04:** Scenario text font upgraded to **Playfair Display** from Google Fonts. High-contrast editorial serif that feels literary and serious.
- **D-05:** UI font upgraded to **Inter** from Google Fonts. Consistent geometric sans-serif across all devices.
- **D-06:** Scenario text sizing and spacing: **Claude's discretion** — generous enough to feel cinematic, tuned to avoid unnecessary scrolling on short scenarios. Likely 20-22px, 1.7+ line-height.

### Component Visual Treatment
- **D-07:** Surface treatment is **glass-morphism** — semi-transparent backgrounds with backdrop-blur, soft glow borders. Content floats over the ambient gradient. Applies to scenario cards, consequence reveals, profile sections, panels.
- **D-08:** Choice buttons use **glow on hover/tap** — amber glow border on hover, subtle scale-up. Selected button glows brighter, others dim/recede. Locked state shows solid amber accent ring.
- **D-09:** World state meter bars upgraded to **gradient fill + glow** — warm amber gradient that shifts cooler when low, subtle glow behind the fill. Still CSS-only, no SVG metaphor meters (those remain v2).

### Transitions & Motion
- **D-10:** Add **Framer Motion** (`framer-motion` 11.x) for page and round transitions. AnimatePresence for enter/exit orchestration.
- **D-11:** Round-to-round transitions use **cinematic fade-through** — current content fades to black, brief hold (0.3-0.5s), new content fades in. Scene-change feel.
- **D-12:** End screen (FrameworkProfile) uses **staggered reveal** — dominant framework fades in first, then conflict map, then least-used prompt, then choice log. Each section enters with a short delay, unfolding like a story.

### Claude's Discretion
- Exact scenario text sizing within the generous/cinematic direction (D-06)
- Specific gradient colors and animation timings for ambient background
- Exact glass-morphism blur radius and opacity values
- Button glow intensity and transition curves
- Meter gradient color stops and glow spread
- Framer Motion spring/tween config values for transitions
- How consequence reveal and content note components are visually upgraded (consistent with glass-morphism direction)

</decisions>

<code_context>
## Existing Code Insights

### Reusable Assets
- **CSS custom properties** (`src/index.css`): `--bg`, `--bg-surface`, `--text`, `--accent`, `--serif`, `--sans` — extend these with new atmospheric vars rather than replacing
- **CSS Modules pattern**: Every component has a `.module.css` — all visual changes go through these files
- **Reduced-motion guard**: Global `@media (prefers-reduced-motion)` in `index.css` — all new animations must respect this

### Established Patterns
- Component state managed via React hooks (`useState`, `useEffect`)
- Supabase real-time subscriptions drive world state updates — visual atmosphere reacts to the same `worldState` prop
- CSS class toggling for danger states (MeterBar already has conditional classes)

### Integration Points
- **World state prop**: `worldState` object passed to components — the new atmosphere tint system reads from this same prop
- **Framer Motion**: New dependency — wraps page-level components and round transitions. Does NOT replace CSS Modules for static styling.
- **Google Fonts**: Two font imports (Playfair Display, Inter) added to `index.html` `<head>` — CSS vars updated to reference them
- **App.jsx routing**: AnimatePresence wraps route outlet for page transitions

</code_context>

<specifics>
## Specific Ideas

- Cinematic fade-through between rounds (fade to black, hold, fade in) — not a slide or crossfade
- End screen reveals like a story unfolding — staggered section entrances with deliberate pacing
- Ambient gradients that never stop moving — the screen should feel alive even when nothing is happening
- World state meters influence the page atmosphere — low meters = cooler/darker ambient, high = warmer

</specifics>
