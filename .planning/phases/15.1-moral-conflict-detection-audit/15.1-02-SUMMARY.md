# Phase 15.1 Plan 02: Wire Full Choice Context to Call Sites Summary

Fixed the two call sites (Play.jsx and ConsequenceReveal.jsx) that passed truncated choice context to findMoralConflicts, preventing the 8 matchCondition STANCE_TRIGGERS and VALUE_CONDITION_TRIGGERS fixed in Plan 01 from ever firing at round-close time.

## What Was Built

### Task 1: Fix Play.jsx — pass full choice context for per-round conflict detection

Two changes in the `round_complete` render block (lines ~484–520):

1. `frameworkKey` variable removed. Replaced with `choiceFrameworks = chosenOption.frameworks ?? []`.

2. `singleHistory` entry now includes all four context fields:
   ```javascript
   const singleHistory = [{
     round: session.current_round,
     scenarioId: currentScenario.id,
     choiceIndex: lockedChoiceIndex,
     frameworks: choiceFrameworks
   }]
   ```

3. `ConsequenceReveal` prop contract updated: `framework={frameworkKey}` replaced with `frameworks={choiceFrameworks}` plus new props `scenarioId={currentScenario.id}`, `choiceIndex={lockedChoiceIndex}`, `round={session.current_round}`.

### Task 2: Fix ConsequenceReveal.jsx — use full frameworks array + scenarioId/choiceIndex

Three changes in ConsequenceReveal:

1. Function signature updated: `framework` (single string) replaced with `frameworks` (array), `scenarioId`, `choiceIndex`, `round`.

2. FRAMEWORKS lookup updated to use `primaryFramework = frameworks?.[0] ?? null` — display logic unchanged, just uses first element of the array.

3. `singleRoundHistory` entry now includes all four context fields:
   ```javascript
   const singleRoundHistory = frameworks?.length > 0 ? [{
     round: round ?? 1,
     scenarioId: scenarioId ?? null,
     choiceIndex: choiceIndex ?? null,
     frameworks
   }] : []
   ```

With these changes, condition-specific triggers added in Plan 01 (VALUE_CONDITION_TRIGGERS for fairness on R1-1/R3-1, STANCE_TRIGGERS for lie_to_protect on R4-2/R4-0) can now fire at round-close time for the player viewing their consequence reveal.
