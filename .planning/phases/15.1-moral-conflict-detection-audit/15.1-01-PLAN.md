<objective>
Fix the three critical bugs in detection.js that cause false-positive moral conflict detection. Audit confirms: (1) fairness maps to a dead framework tag (distributive_justice) that never appears in any scenario choice — every fairness-first player gets a conflict on every round; (2) two STANCE_TRIGGERS use matchFramework which fires on every round containing that framework tag instead of only on the specific rounds where the stance is actually tested.

Purpose: Players who rank fairness first currently see "This choice conflicts with your stated value of fairness" after every single decision they make, including choices entirely unrelated to fairness. The lie_to_protect triggers fire on 7+ unrelated rounds. These false positives corrupt the game's pedagogical signal — the end screen conflict analysis is meaningless noise.

Output: Corrected detection.js with VALUE_CONDITION_TRIGGERS array for fairness + 4 specific matchCondition entries replacing the 2 broad matchFramework entries. Updated test file with coverage for fixed behaviors.
</objective>
