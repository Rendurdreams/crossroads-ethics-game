# Phase 15.1 Plan 01: Fix Moral Conflict Detection False Positives Summary

Fixed three critical bugs in detection.js: dead fairness framework tag causes all-rounds false positives for fairness-first players, and two matchFramework STANCE_TRIGGERS fire on 6-7 unrelated rounds instead of the 2 specific rounds where the stance is actually tested.

## What Was Built

### Task 1: Fix detection.js

Three structural changes:

1. `VALUE_FRAMEWORK_MAP.fairness` changed from `['distributive_justice']` to `[]` — the tag `distributive_justice` appears on zero scenario choices, making the alignment check always false for fairness-first players.

2. `VALUE_CONDITION_TRIGGERS` array added (2 entries for fairness): fires value-type conflicts only when the choice is exactly `round-1/choiceIndex 1` ("Protect the Core") or `round-3/choiceIndex 1` ("Deny petition") — the two specific rounds where fairness-first reasoning is actually challenged.

3. Two `matchFramework` STANCE_TRIGGERS for `lie_to_protect` replaced with four `matchCondition` entries targeting the specific round+choiceIndex pairs: `round-4/2` and `round-bombshell/1` for `stanceAnswer: 'no'`; `round-4/0` and `round-bombshell/0` for `stanceAnswer: 'yes'`.

4. `usesConditionTriggers` guard added to `findMoralConflicts` — skips the framework-based value loop when the top value is handled by condition triggers. Prevents fairness from falling through to the generic "no alignment → conflict" path.

### Task 2: Update detection.test.js

- Updated fairness `VALUE_FRAMEWORK_MAP` assertion to expect empty array
- Fixed mc9 test: with fairness using condition triggers, round-5/choiceIndex-0 no longer produces a value conflict — stance conflict fires instead (correct new behavior)
- Updated mc7 comment to reflect matchCondition (not matchFramework)
- Added 14 new tests covering all fixed behaviors:
  - fairness false positive elimination (non-condition round → no conflict)
  - fairness condition triggers (R1-1 and R3-1, exact messages verified)
  - lie_to_protect=no false positive fix (round-1/0 → no conflict)
  - lie_to_protect=no bombshell condition (round-bombshell/1 → stance conflict)
  - lie_to_protect=yes false positive fix (round-1/2 → no conflict)
  - lie_to_protect=yes bombshell condition (round-bombshell/0 → stance conflict)

| Decision | Rationale |
