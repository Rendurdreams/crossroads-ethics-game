**Per D-09 — Split the homepage into cleaner host vs player sections.**

The current Landing.jsx has both "Begin" (create session) and "Enter" (join session) in a single stacked page. The split should make these visually distinct entry paths while keeping them on the same page (no new routes needed — the sections are just more clearly separated).

Redesign Landing.jsx:

1. The page opens with the title and a choice: "Are you the ruler or a councillor?"
2. Two large cards/zones side by side (stacking on mobile):
   - **Left card: "CONVENE THE COUNCIL"** (for the host)
     - Description: "You are the ruler. Create a chamber for your council."
     - Button: "Convene" (same createSession logic)
   - **Right card: "JOIN THE COUNCIL"** (for the player)
     - Room code input
     - Name input
     - Button: "Enter" (same joinSession logic)

The logic inside each section remains IDENTICAL to current Landing.jsx. This is a visual redesign only — no functional changes to createSession or joinSession.
