**Part A — HowOthersChose component (per D-04):**

Create `src/components/HowOthersChose.jsx`:

Props: `{ scenarioId, liveChoices, totalPlayers }`
- `scenarioId`: string like 'round-1' — used to look up reference data
- `liveChoices`: array of choice objects from the round (from roundState.choices in Host, or computed tally in Play)
- `totalPlayers`: number — total players in session

The component:
1. Imports `getHowOthersChose` from `../lib/howOthersChose.js`
2. Gets reference data: `const reference = getHowOthersChose(scenarioId)`
3. Computes live class percentages from `liveChoices` (group by choice_index, compute pct)
4. Renders a comparison view:

```jsx
<div className={styles.container}>
  <p className={styles.heading}>How Others Chose</p>
  <p className={styles.subheading}>Research baseline vs. your class</p>
  {reference?.map((ref) => {
    const liveCount = liveChoices.filter(c => c.choice_index === ref.choiceIndex).length
    const livePct = totalPlayers > 0 ? Math.round((liveCount / totalPlayers) * 100) : 0
    return (
      <div key={ref.choiceIndex} className={styles.row}>
        <span className={styles.label}>{ref.label}</span>
        <div className={styles.bars}>
          <div className={styles.barGroup}>
            <div className={styles.barTrack}>
              <div className={styles.barRef} style={{ width: `${ref.pct}%` }} />
            </div>
            <span className={styles.pctLabel}>{ref.pct}%</span>
          </div>
          <div className={styles.barGroup}>
            <div className={styles.barTrack}>
              <div className={styles.barLive} style={{ width: `${livePct}%` }} />
            </div>
            <span className={styles.pctLabel}>{livePct}%</span>
          </div>
        </div>
      </div>
    )
  })}
  <div className={styles.legend}>
    <span className={styles.legendRef}>Research</span>
    <span className={styles.legendLive}>Your class</span>
  </div>
</div>
```

**Part B — WalkMechanic component (per D-03):**

Create `src/components/WalkMechanic.jsx`:

Props: `{ onChoice, submitting, lockedIndex }`

The walk mechanic replaces standard choice buttons for Round 6 only. Instead of tapping a button, the player taps/swipes left or right to "walk" their avatar.

Implementation (Claude's discretion — directional tap):
- Show a horizontal track with a figure/avatar icon in the center
- Left side labeled: "Walk to the shackles" (Choice I — Free Irel, choiceIndex 0)
- Right side labeled: "Walk away" (Choice II — Maintain binding, choiceIndex 1)
- Center button appears after a brief delay (1.5s): "Commission scholars" (Choice III, choiceIndex 2)
- Tapping left/right side triggers `onChoice(0)` / `onChoice(1)`, center button triggers `onChoice(2)`
- Once locked, the avatar slides to the chosen side with a CSS transition
- The visual should feel like a physical movement, not a menu selection

```jsx
import { useState } from 'react'
import styles from './WalkMechanic.module.css'

export default function WalkMechanic({ onChoice, submitting, lockedIndex }) {
  const [showMiddle, setShowMiddle] = useState(false)

  // Show middle option after 1.5s delay
  useState(() => {
    const timer = setTimeout(() => setShowMiddle(true), 1500)
    return () => clearTimeout(timer)
  })

  const isLocked = lockedIndex !== null
  const avatarPosition = lockedIndex === 0 ? 'left' : lockedIndex === 1 ? 'right' : lockedIndex === 2 ? 'center' : 'middle'

  return (
    <div className={styles.walkContainer}>
      <p className={styles.instruction}>Walk toward your choice</p>

      <div className={styles.track}>
        <button
          className={`${styles.zone} ${styles.zoneLeft} ${lockedIndex === 0 ? styles.zoneLocked : ''} ${isLocked && lockedIndex !== 0 ? styles.zoneDimmed : ''}`}
          onClick={() => !submitting && onChoice(0)}
          disabled={submitting}
        >
          <span className={styles.zoneIcon}>⛓️</span>
          <span className={styles.zoneLabel}>Free Irel</span>
        </button>

        <div className={`${styles.avatar} ${isLocked ? styles[`avatar${avatarPosition.charAt(0).toUpperCase() + avatarPosition.slice(1)}`] : ''}`}>
          🚶
        </div>

        <button
          className={`${styles.zone} ${styles.zoneRight} ${lockedIndex === 1 ? styles.zoneLocked : ''} ${isLocked && lockedIndex !== 1 ? styles.zoneDimmed : ''}`}
          onClick={() => !submitting && onChoice(1)}
          disabled={submitting}
        >
          <span className={styles.zoneIcon}>🚪</span>
          <span className={styles.zoneLabel}>Walk away</span>
        </button>
      </div>

      {showMiddle && (
        <button
          className={`${styles.middleBtn} ${lockedIndex === 2 ? styles.zoneLocked : ''} ${isLocked && lockedIndex !== 2 ? styles.zoneDimmed : ''}`}
          onClick={() => !submitting && onChoice(2)}
          disabled={submitting}
        >
          Commission scholars — one year
        </button>
      )}
    </div>
  )
}
```

CSS: The track is a horizontal bar. Avatar uses `transition: transform 0.6s ease`. On lock, avatar translates left or right. Left zone has a warm glow, right zone is darker. Mobile-optimized full-width.

Use `useEffect` (not `useState`) for the 1.5s delay timer.
