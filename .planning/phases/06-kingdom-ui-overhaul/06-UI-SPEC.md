## Component Inventory

### New Components

#### `KingdomMap` (`src/components/KingdomMap.jsx` + `KingdomMap.module.css`)

**Purpose:** Replaces `CityScene` / `CityPlaceholder` on host screen. Renders a full-panel SVG fantasy map with named landmark regions that react to `worldState` prop.

**Props:** `worldState: { trust, courage, solidarity, awareness }` (0–100 each)

**SVG structure:**
- Viewport: `viewBox="0 0 800 500"` — fills 100% of container, `preserveAspectRatio="xMidYMid meet"`
- Background: deep space fill matching `--bg` (`#0a0a14`)
- Terrain layer: SVG `<polygon>` / `<path>` shapes for mountain range (upper-right), river curve (diagonal center-left to lower-right), coastal shelf (lower-right), forest cluster (left), and a mound/hill for the village (center-left)
- Landmark icons embedded in terrain: each is a small SVG group (`<g>`) with a distinctive silhouette shape at fixed coordinates
- Ground plane: low horizontal rectangle at bottom, color `#14142a`

**Four landmarks (coordinates are conceptual; exact values are Claude's discretion):**

| Landmark | World State | Map Region | Silhouette Shape |
|----------|-------------|------------|------------------|
| Bridge of Accord | trust | River center crossing | Arch bridge with two piers, cable suggestion |
| Citadel Beacon | courage | Mountain peak upper-right | Tower cylinder with pointed cap + SpotLight ray sweep as SVG line |
| Village Quarter | solidarity | Center-left plain | Cluster of 3–4 small house rectangles with chimney, warm windows |
| Fog of the Vale | awareness | Lower-left coastal lowland | SVG fog layer (`<ellipse>` or `<path>`) as semi-transparent fill; more opaque when awareness declines |

**Tier CSS classes on each landmark `<g>`:**
- `.flourishing` — `filter: drop-shadow(0 0 12px var(--landmark-flourishing-glow)); fill: var(--landmark-flourishing)`
- `.neutral` — `filter: drop-shadow(0 0 6px var(--landmark-neutral-glow)); fill: var(--landmark-neutral)`
- `.declining` — `filter: none; fill: var(--landmark-declining); opacity: 0.5`

**Tier transitions:** `transition: fill 1.2s ease, filter 1.2s ease, opacity 1.2s ease` — CSS only, no Framer Motion.

**Tier threshold logic (inside `KingdomMap.jsx`):**
```js
function getTier(value) {
  if (value >= 70) return 'flourishing'
  if (value >= 40) return 'neutral'
  return 'declining'
}
```

**Landmark name labels:** Each landmark has an SVG `<text>` label below its icon. Font: Playfair Display (loaded as web font), size 11px, fill `rgba(245,158,11,0.6)`, letter-spacing 0.1em. Exact label text = landmark names from D-03.

**Map panel placement in Host.jsx:**
- Container takes `flex: 3` (≈60% width) in the `bottomPanels` layout
- Map fills the panel with `width: 100%; height: auto`
- Glass panel wrapper applies existing `.glassPanel` card style

## State Transition Visual Contract

### Landmark tier transitions (KingdomMap)

Tier changes are driven by `worldState` prop updates after each round close. CSS handles animation:

```
flourishing → neutral: fill darkens, glow reduces — 1.2s ease
neutral → declining: fill shifts to cool-grey, glow removed — 1.2s ease
declining → neutral / flourishing: reverse — 1.2s ease
```

No threshold event animations in this phase (VIS-02 is v2 scope — CONTEXT.md deferred).

### Decree tile lock state (Play.jsx / ScenarioCard)

Lock state behavior unchanged from Phase 05.1:
- Locked tile: `border: 2px solid var(--accent); background: rgba(245,158,11,0.12); box-shadow: 0 0 20px var(--glow-amber-strong)`
- Roman numeral numeral inside locked tile: color var(--accent), weight 700 (unchanged — already amber)
- Dimmed tiles: `opacity: 0.3; filter: grayscale(30%)`

## SVG Design Guidance (Claude's Discretion)

The following are implementation guidelines for the KingdomMap SVG. Exact coordinates are the executor's responsibility.

**Overall composition (800 × 500 viewBox):**
- Mountains: upper-right quadrant, 3–4 polygon peaks, fill `#1a1a2e` to `#16162a`
- River: diagonal S-curve from upper-center to lower-right, width 8–12px, fill `rgba(59,130,246,0.18)` (subtle blue, consistent with existing `--glow-cool`)
- Coastal shelf: lower-right flat area, fill `rgba(59,130,246,0.08)`
- Forest cluster: left side, 5–7 simple triangle trees, fill `#141428`
- Village mound: center-left, gently raised polygon, fill `#16162a`

**Landmark silhouettes** (drawn in amber/neutral fill, tier class applied by JS):
- Bridge of Accord: river crossing area — two arch piers + horizontal span, approx 80px wide, 30px tall SVG group
- Citadel Beacon: mountain peak — tower 12px wide × 35px tall, pointed cap, single upward ray line (stroke only, not fill)
- Village Quarter: center-left mound — 3 small house rects (12px × 10px) with 1px chimney each, clustered
- Fog of the Vale: lower-left — a semi-transparent horizontal ellipse that grows more opaque as awareness declines; `opacity` driven by CSS class (flourishing: 0.15, neutral: 0.35, declining: 0.6)

**Landmark label `<text>` positioning:** 8px below each landmark group centroid. `text-anchor="middle"`.

**Crest/sigil (Landing page):** Simple heraldic shield outline (4 SVG path nodes) with a crossroads X motif inside. Width: 64px, height: 72px. Fill: `rgba(245,158,11,0.7)`, no stroke. Centered above headline.
