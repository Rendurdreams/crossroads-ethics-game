# Compact Meter Strip with Color-Coded Axes

<objective>
Replace the tall expandable WorldHealthBar on the player phone with a compact monospace status strip showing all 4 meters in a single line at the top of the screen, each meter in its own distinct color with green/red delta arrows after round close.
</objective>

<tasks>

<task id="T1" title="Create CompactMeterStrip component">
<read_first>
- src/components/MeterBar.jsx
- src/components/MeterBar.module.css
- src/lib/axisConstants.js
</read_first>
<action>
Create `src/components/CompactMeterStrip.jsx` with these specs:

Props: `worldState` (object), `pack` (object), `roundClosed` (boolean)

Internal logic:
1. Call `getAxisLabels(pack)` to get axis key-label map
2. Track previous world state via `useRef` — on each render where values differ, compute deltas per axis and store them. Only clear deltas when `roundClosed` transitions from true back to false (new round starts).
3. Define a color map object:
   - For kingdom-arc axes: `{ trust: '#3b82f6', courage: '#f59e0b', solidarity: '#22c55e', awareness: '#a855f7' }` (blue, amber, green, purple)
   - For signal-lost axes: `{ CT: '#3b82f6', HD: '#a855f7', SOL: '#22c55e', ACC: '#f59e0b' }` (blue, purple, green, amber)
   - Merge both into a single `METER_COLORS` constant — axis keys are unique across packs so no collision
4. Define abbreviation map: `{ trust: 'HON', courage: 'CRG', solidarity: 'LOY', awareness: 'EMP', CT: 'CT', HD: 'HD', SOL: 'SOL', ACC: 'ACC' }`
5. Render a single flex row. For each axis key, render:
   - Abbreviation label in the meter's color
   - Numeric value (Math.round) in the meter's color
   - If `roundClosed` is true AND delta exists for this axis: render `▲` in `#22c55e` (green) if delta > 0, `▼` in `#ef4444` (red) if delta < 0
6. Export default.

The component should import `getAxisLabels` from `../lib/axisConstants.js`.
</action>

</task>
