Add a `.scenarioOverlay` class to Host.module.css. Position it as a semi-transparent overlay at the top of the screen, below the HUD pills but above the 3D canvas. Insert this after the existing `.scenarioBody` rule (after line ~126, before the Vote tally section):

```css
.scenarioOverlay {
  position: fixed;
  top: 60px;
  left: 50%;
  transform: translateX(-50%);
  width: 60%;
  max-width: 720px;
  max-height: 40vh;
  overflow-y: auto;
  background: rgba(18, 18, 30, 0.85);
  backdrop-filter: blur(8px);
  border-radius: 12px;
  padding: 20px 28px;
  z-index: 10;
  pointer-events: none;
}

.scenarioOverlay .scenarioTitle {
  font-size: 15px;
  margin-bottom: 10px;
}

.scenarioOverlay .scenarioBody {
  font-size: 16px;
  line-height: 1.65;
}
```

Key design decisions:
- `position: fixed` keeps it stable over the canvas
- `top: 60px` clears the top HUD pills
- `width: 60%` centered leaves room for side HUD elements
- `max-height: 40vh` with `overflow-y: auto` prevents long scenarios from covering the whole screen
- `background: rgba(18, 18, 30, 0.85)` with backdrop blur matches the glass pill aesthetic from Phase 10
- `pointer-events: none` so clicks pass through to the canvas
- `z-index: 10` — above canvas (z-index auto) but below HUD pills and overlays
