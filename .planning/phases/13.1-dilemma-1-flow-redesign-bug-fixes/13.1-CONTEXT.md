## Implementation Decisions

### Bombshell Round
- Replace Round 8 "The Reckoning" (choices: []) in kingdom-arc.js with a new bombshell scenario with 3 real choices and 2-3x worldImpact values
- Same round mechanics as Rounds 1-7: 3 choices, timer, submit, host closes round
- After host closes bombshell round → reveal → "The Verdict" overlay (not "THE LESSON") → "End Game" button → endSession()
- Fix totalRounds math: getPlayableScenarios() returns 8 since bombshell has choices — HostSetup.jsx must set total_rounds = 8, not 9
- Reflection textarea on player end screen (FrameworkProfile.jsx) remains functional for post-game use — it is no longer an in-game round

### Host Score Display Fix
- Host.jsx METER_LABELS must be {trust: 'Honesty', courage: 'Courage', solidarity: 'Loyalty', awareness: 'Empathy'}
- Currently shows old names — affects delta pills after reveal animation

### Player Answer Toggle
- Remove early-return guard on lockedChoiceIndex in handleChoice() (Play.jsx)
- Use upsert or delete+re-insert to handle unique constraint on (session_id, player_id, round_number)
- Player can change selection at any time before round closes
- Host vote tally must stay accurate (no double-counting)

### Question on Host Screen
- Add scenario title + body text to host active round view — always visible, not behind a toggle
- Presenter needs to see/read the question aloud from the projected screen

### Language/Copy
- Bombshell scenario copy must feel like the climax — punchy, dramatic, high-stakes
- Host status during bombshell: distinct from "The Council Deliberates" (e.g. "The Final Reckoning")
- Bombshell reveal: distinct from "The Realm Shifts..." (e.g. "The Throne Speaks...")
- Bombshell overlay label: "THE VERDICT" not "THE LESSON"
- Keep kingdom atmospheric framing throughout

### Claude's Discretion

- Exact copy for host status text and reveal text during bombshell round
- CSS styling/positioning for the scenario text on host active screen

- How to detect "is bombshell round" in Host.jsx for conditional overlay label
