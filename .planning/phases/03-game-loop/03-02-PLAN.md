    SIMPLER APPROACH for v1: The player timer mirrors the host's timer. Since there's no timer column in the DB, use a local `setInterval` on the player side too.     SIMPLEST v1 APPROACH: Skip the player-side timer countdown for now. Show TimerDisplay only on the host (Plan 03). D-05 says timer shown on player phone, but without a DB column for timer state, adding one requires a schema migration. Mark this as a limitation and implement the submitted counter (PLAY-08) instead. If the team wants player timer, it needs a schema change (add `timer_remaining` column to sessions or use a Supabase broadcast channel).

    RESOLUTION: Use Supabase Broadcast channel (not postgres_changes) for timer sync. Host broadcasts `{ type: 'timer', remaining: N, total: T }` every second. Player subscribes to the broadcast channel and updates local state. This avoids schema changes and gives real-time timer without DB writes. Channel: `timer:${sessionId}`.

    Player-side timer subscription (new useEffect):
    ```
    useEffect(() => {
      if (!sessionId || !gameStarted) return
      const channel = supabase.channel(`timer:${sessionId}`)
        .on('broadcast', { event: 'timer' }, (payload) => {
          setTimerRemaining(payload.payload.remaining)
          setTimerTotal(payload.payload.total)
        })
        .subscribe()
      return () => supabase.removeChannel(channel)
    }, [sessionId, gameStarted])
    ```

    **Choice submission handler (PLAY-05):**
    ```
    async function handleChoice(choiceIndex) {
      if (lockedChoiceIndex !== null || submitting) return
      setLockedChoiceIndex(choiceIndex)
      setSubmitting(true)
      setSubmitError(false)

      const currentScenario = scenarios[session.current_round - 1]
      const { error } = await supabase.from('choices').insert({
        session_id: sessionId,
        player_id: player.id,
        round_number: session.current_round,
        scenario_id: currentScenario.id,
        choice_index: choiceIndex,
        frameworks: currentScenario.choices[choiceIndex].frameworks
      })

      setSubmitting(false)
      if (error) {
        if (error.code !== '23505') {
          setLockedChoiceIndex(null)
          setSubmitError(true)
        }
        // 23505 = UNIQUE violation = already submitted, keep locked
      }
    }
    ```
