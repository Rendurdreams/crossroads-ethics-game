**Step 1: Source and commit GLTF models (per D-02, D-03, D-04)**

Create `public/models/` directory. Download CC0 medieval/fantasy GLTF models:

- **Primary source:** Kenney Fantasy Town Kit (https://kenney.nl/assets/fantasy-town-kit) — CC0, 160+ GLB models
- **Backup sources:** Poly Pizza (https://poly.pizza), Quaternius Medieval Village Pack

Download the kit archive. From the extracted files, select:
- A stone bridge model → save as `public/models/bridge.glb`
- A tall tower/lighthouse model → save as `public/models/beacon-tower.glb`
- 1-3 house/hut models (or a pre-composed cluster) → save as `public/models/village-cluster.glb`
- A terrain/ground tile → save as `public/models/terrain.glb`

After placing models, inspect each one to discover actual mesh/material names:
```bash
npx gltfjsx public/models/bridge.glb --output /dev/stdout 2>/dev/null | head -30
npx gltfjsx public/models/beacon-tower.glb --output /dev/stdout 2>/dev/null | head -30
npx gltfjsx public/models/village-cluster.glb --output /dev/stdout 2>/dev/null | head -30
npx gltfjsx public/models/terrain.glb --output /dev/stdout 2>/dev/null | head -30
```

If `npx gltfjsx` is unavailable or fails, load each model in the R3F component and `console.log(Object.keys(nodes), Object.keys(materials))` to discover names. The actual mesh/material names from the downloaded files MUST be used in code — do NOT guess names like `bridge_mesh` or `bridge_stone`.

**Step 2: Create src/components/KingdomScene.jsx (per D-01, D-05, D-06)**

Use CityScene.jsx as the architectural template. The new file must:

1. Import from `react` (useRef, useMemo, useEffect), `@react-three/fiber` (Canvas, useFrame, useThree), `@react-three/drei` (OrbitControls, Stars, useGLTF), and `three` (as `* as THREE`)

2. Call `useGLTF.preload()` at module level for all 4 model paths — prevents React 19 Suspense waterfall:
   ```js
   useGLTF.preload('/models/bridge.glb')
   useGLTF.preload('/models/beacon-tower.glb')
   useGLTF.preload('/models/village-cluster.glb')
   useGLTF.preload('/models/terrain.glb')
   ```

3. Create sub-components, each loading its own GLTF via `useGLTF()`:
   - `Bridge({ trust })` — loads `/models/bridge.glb`, renders via `<primitive object={nodes[ACTUAL_NAME]} />`
   - `BeaconTower({ courage })` — loads `/models/beacon-tower.glb`, renders via `<primitive>`
   - `VillageQuarter({ solidarity })` — loads `/models/village-cluster.glb`. If using multiple separate house GLBs, position 3-5 in a `<group>` with offsets
   - `FogController({ awareness })` — no GLTF needed; identical to CityScene.jsx pattern: `const { scene } = useThree()` + `useEffect` setting `scene.fog = new THREE.FogExp2('#0a0a14', density)` where density = `0.015 + (1 - awareness / 100) * 0.04` (inverted per D-10)
   - `Ground()` — loads `/models/terrain.glb` or uses a simple plane if terrain model is not suitable
   - `CameraRig()` — copy from CityScene.jsx: OrbitControls with `autoRotate=true`, `autoRotateSpeed=0.3`, `enablePan=false`, `minPolarAngle=Math.PI/6`, `maxPolarAngle=Math.PI/2.5`, `minDistance=8`, `maxDistance=30`, `target=[0, 2, 0]`
   - `Particles()` — copy from CityScene.jsx: 200 amber points with slow drift

4. For this plan, each landmark sub-component receives its meter prop but only uses it minimally (e.g. bridge emissive set to `trust / 100` statically, beacon light on/off based on `courage > 20`). Full lerp interpolation and threshold events are Plan 02 work.

5. Export default `KingdomScene({ worldState })` rendering a `<Canvas>` with:
   - `camera={{ position: [12, 8, 15], fov: 50 }}`
   - `gl={{ antialias: true, alpha: false }}`
   - `style={{ background: '#050510' }}`
   - `shadows` prop
   - Children: FogController, ambientLight (intensity 0.08, color "#4a4a6a"), directionalLight, pointLight (amber "#f59e0b"), Stars (radius 50, depth 50, count 2000, factor 3, saturation 0, fade, speed 0.5), Bridge, BeaconTower, VillageQuarter, Ground, Particles, CameraRig

6. For each GLTF material that needs modification, clone in `useMemo` (per research anti-pattern guidance): `const mat = useMemo(() => materials['ACTUAL_NAME']?.clone() ?? new THREE.MeshStandardMaterial(), [materials])`

7. If any GLTF textures appear washed out (R3F v9 color space issue), fix with: `texture.colorSpace = THREE.SRGBColorSpace` in a useEffect after load. Kenney low-poly models likely use vertex colors, so this may not be needed.

8. Position and scale each landmark model so the composition looks like a nighttime kingdom viewed from slight elevation. Adjust `position` and `scale` props on each `<primitive>` or wrapping `<group>` until the scene reads well. Bridge roughly center, beacon on elevated right, village cluster center-left, terrain as ground plane.
