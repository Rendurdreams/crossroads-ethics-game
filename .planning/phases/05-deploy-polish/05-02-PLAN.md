    **src/index.css — add color-scheme to :root block (per UI-SPEC Design System table):**
    Add `color-scheme: dark;` inside the existing `:root` block, after the `--mono` variable declaration (line 13) and before the `font:` shorthand (line 15). This prevents iOS browser chrome from rendering light-colored form elements and scrollbars.

    **src/index.css — add global reduced-motion media query (per UI-SPEC Animation Contract):**
    Append at the end of the file (after the `#root` block):
    ```css
    @media (prefers-reduced-motion: reduce) {
      *,
      *::before,
      *::after {
        animation-duration: 0.01ms !important;
        transition-duration: 0.01ms !important;
      }
    }
    ```
    This global guard catches all animations. Individual component `@media (prefers-reduced-motion)` rules in FrameworkProfile.module.css and Play.module.css still apply but the global rule provides a safety net for any component that forgets.

    **src/pages/Play.module.css — add overscroll-behavior to .gameContent (per D-11, UI-SPEC Mobile Audit Contract):**
    Add `overscroll-behavior: contain;` to the `.gameContent` rule (line 63). This prevents accidental browser back-swipe on iOS when scrolling to the top of the game content area.
